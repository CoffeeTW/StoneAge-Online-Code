# Triage labels

工程 skills 使用五個標準 triage roles。本文件將這些 roles 對應到 GitHub Issues 實際使用的 label 字串。

| mattpocock/skills role | GitHub label | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待 maintainer 評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由 agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要由人員實作或處理 |
| `wontfix` | `wontfix` | 決定不處理 |

當 skill 提及某個 triage role 時，使用上表對應的 GitHub label。

如果未來 repository 改用其他 label 命名，只需修改 `GitHub label` 欄位，避免建立重複 label。
